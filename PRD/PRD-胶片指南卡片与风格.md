# PRD（产品需求文档）— 胶片指南卡片、场景筛选与风格

**日期**：2026-10-12 · **状态**：第一版已在分支 `feature/film-guide-styles` 实现（2026-10-12，见 §11.1）；负责人已于同日答复 Q1、Q5、Q11（见 §11.1）。文中所有标"草稿"的内容都待负责人确认。
**起草**：根据一位只用过数码相机的新用户的反馈和需求整理。
**关联**：[设置剪贴板 PRD](./PRD-settings-clipboard.md)（§7 预留的"预设"）、[RFC-027](../rfc/RFC-027-settings-clipboard.md)（设计记录：剪贴板的实现）、[RFC-030](../rfc/RFC-030-film-character-contrast-and-grain.md)（每款胶片自己的颗粒）、[彩色胶片颗粒研究](../research/colour-film-granularity.md)。
**实现**：本 PRD 通过后另写 RFC。
**路径约定**：下文的 Swift 代码路径相对于 `modern_UI/Spektrafilm/Spektrafilm/`；引擎、工具、测试写全路径或类名。

**前提约束**
- **不污染材质模型。** 卡片只展示，风格只设参数，任何功能都不修改胶片或相纸的配置文件（`ARCHITECTURE.md` §1）。
- **风格属于"编辑配方"，不是导出配方。** 它和设置剪贴板是同一类东西：剪贴板 PRD §7 写明"预设就是存了名字的剪贴板"，本 PRD 兑现这一条。
- **冲洗后调整（Post-Dev）不进入风格。** 2026-09-23 的产品定位把它排除在编辑模型之外，剪贴板也不复制它（`Model/SettingsClipboard.swift` 的 `notCopied`）。
- 新界面要先出设计稿并由负责人确认。本 PRD 里的布局示意只说明内容和顺序，不是设计稿。

---

## 1. 为什么

一位只用过数码相机的用户第一次打开胶片列表时的反馈（原话）：

> 胶片和相纸就是模拟的真实胶片和真实相纸对么……每个胶片和相纸都有什么特性我该从哪查呢？不会要我自己一个一个试吧？
>
> 当把鼠标放上去应该展示胶片信息，最好有实体胶片的样子更容易让小白记住是哪款胶片，然后列出胶片适合的场景供用户筛选……我对这些根本不了解只能一个一个试，体验太差了。

现状（已对照代码）：
- 胶片列表只有名字，24 款胶片、9 款相纸都没有说明。胶片行的悬停提示是空的：`Panels/Sections/FilmSection.swift` 第 53 行传入 `help: ""`。
- 列表按技术类型分组（正片 / 负片 / 黑白，`StockCatalog.filmGroups`），对新手没有帮助。
- 仓库里有 16 张胶片包装照片（`modern_UI/film_covers/`），其中 11 张被打包进应用；`Stock.cover` 字段和取图方法 `coverURL` 都写好了，但**没有任何调用方**。这些照片也没有来源和授权记录。
- 用户想把一卷照片统一成某种胶片效果，现在只能逐个试胶片，再用设置剪贴板同步。

目标：
1. 没有胶片知识的用户，不靠逐个试，也能看懂每款胶片和相纸大致是什么效果、适合什么场景。
2. 一键套用一种"风格"（胶片 + 相纸 + 效果强度），并能直接作用于选中的一批照片。
3. 用户能把自己调好的设置存成风格，以后一键套用。

目标流程（批量）：打开文件夹 → ⌘A 全选 → 在"风格"里点一个 → ⌘E 导出。

## 2. 范围

| | 内容 |
|---|---|
| **做** | A. 胶片与相纸的悬停介绍卡片（33 款）；B. 胶片列表的场景筛选；C. 左栏"风格"分区：内置风格 + 用户自存的风格 |
| **不做** | 用用户自己的照片做悬停预览（需要临时渲染，另立需求）；冲洗后调整进入风格；Agent 工具（命令行、MCP）支持风格；风格的导入导出；跨照片撤销。见 §12 |

## 3. 功能 A：介绍卡片

### 3.1 触发与关闭

- 鼠标停在**胶片行或相纸行**上约 0.5 秒，弹出这一款的卡片。
- 分组标题（正片、负片、黑白、Still、Cine 等）不触发。
- 相纸列表里的"数字中间片"和"不经相纸（直接扫描）"两行不是相纸，不弹卡片，保留它们现有的提示文字。
- 列表正在滚动时不触发。
- 鼠标移出行，卡片消失；移到另一行，卡片切换到那一款。
- 卡片**不抢键盘焦点、不挡点击**：卡片显示时，点击行照常选中这一款。
- 卡片只读：显示卡片不改变任何参数、不写 sidecar（照片旁参数文件）、不触发渲染。

### 3.2 位置与形态

弹在左栏右侧，盖住画布一角，箭头指向所悬停的行。

```
左栏                    卡片（覆盖在画布上）
▽ 胶片          ┌────────────────────────────────────────────┐
   …            │ ┌──────────┐  Kodak Portra 400              │
 ▸ Kodak Portra ◀┤ │  示意图   │  彩色负片 · ISO 400             │
   400          │ │          │  肤色自然、宽容度大……（草稿）     │
   …            │ └──────────┘                                │
                │ 适合   [人像] [街拍日常]                       │
                │ 反差 ●●○○○   饱和度 ●●○○○   宽容度 ●●●●○      │
                │ 颗粒   见 §3.6                                │
                │ 默认相纸  Kodak Professional Portra Endura     │
                │ 画幅   135 · 120                              │
                └────────────────────────────────────────────┘
```

### 3.3 胶片卡片的内容

| 项 | 内容 | 来源 |
|---|---|---|
| 示意图 | 设计师统一绘制的矢量图（附录 C） | `modern_UI/stock_art/<id>.svg` |
| 名称 | 原名，不翻译（`modern_UI/design/LOCALIZATION-zh-Hans.md` 的规则） | 目录 `name` |
| 类型与感光度 | 彩色负片 / 反转片 / 黑白负片 / 电影负片，加 ISO | 目录 `type`、`use`、`monochrome`；ISO 取自名称 |
| 一句话简介 | 中英文各一句（草稿，附录 B） | `stock_guide.json` |
| 适合场景 | 标签，与 §4 的筛选标签是同一套词表 | `stock_guide.json` 加数据推导 |
| 指标 | 反差、饱和度、宽容度、颗粒（§3.5、§3.6） | `stock_traits.json`（测量生成） |
| 默认相纸 | 选这款胶片时自动配上的相纸；反转片写"直接扫描，不经相纸" | 目录 `targetPrint`；规则见 `Session.selectFilmStock` |
| 画幅 | 厂商生产过的规格，如 135、120、16mm | 目录 `formats` |

### 3.4 相纸卡片的内容

| 项 | 内容 | 来源 |
|---|---|---|
| 示意图 | 相纸盒或拷贝片片盘（附录 C） | `modern_UI/stock_art/<id>.svg` |
| 名称、类型 | 彩色相纸 / 电影拷贝片 / 黑白相纸 | 目录 |
| 一句话简介 | 草稿 | `stock_guide.json` |
| 指标 | 反差、饱和度（用参考胶片测，附录 A） | `stock_traits.json` |
| 常见搭配 | 以它为默认相纸的胶片（按胶片的 `targetPrint` 反查） | 目录 |
| 快速切换 | 原有提示"Fast flip available — baked against …"并入卡片，不再单独弹系统提示 | `Panels/Sections/PrintProfileSection.swift` 第 191–193 行 `helpFor` |

当前胶片是反转片时，相纸不参与成像。相纸卡片照常显示，但加一行"当前胶片为反转片，不经相纸"。

### 3.5 指标：只放测得出来的

- **测量对象是"胶片 + 它的默认相纸"。** 同一款胶片印在不同相纸上效果不同，卡片上注明这一点。反转片直接测扫描结果；相纸用固定的参考胶片测。方法见附录 A。
- **显示为 5 档圆点**，档位在同一环节（胶片或相纸）实测范围内**线性**划分：最小值为 1 档，最大值为 5 档，中间按比例取整。所以它表示"在同类里相对偏高还是偏低"，不是绝对值。悬停在圆点上显示原始数值。
- **不用分位数**（2026-10-12 实现时改）：彩色负片的颗粒实测几乎相同（§3.6），分位数会把几乎相同的数值硬分到 1～5 档，凭空造出差别；线性划分下它们会落在同一档。
- **悬停在指标上**显示原始数值、单位、来源（"本软件实测"或"厂商资料"），以及测量时用的相纸。
- **测不出来的就空着**，不用主观描述填。黑白胶片和黑白相纸没有"饱和度"一项。
- 宽容度指**影调**宽容度。色彩在暗部比影调消失得更早（`AGENTS.md` 陷阱 31），悬停说明里写明。

### 3.6 颗粒：需要负责人先定（待决 Q3）

实测发现：本软件目前给**彩色负片**渲染的颗粒几乎一样粗。所有彩色负片的视觉颗粒度都落在一个很窄的区间，和感光度无关：Portra 160 和 Portra 800 一样粗，Vision3 50D 和 500T 一样粗（`research/colour-film-granularity.md` §3）。

每款胶片单独的颗粒量目前只给黑白胶片做了：颗粒强度 1 对应厂商公布的颗粒度，线上值 Tri-X 1.70、HP5 Plus 1.49、T-Max 0.74、Acros II 0.64（提交 `0bca29d`，`FilmParams.ownGrain`）。彩色胶片还在等真实数据（RFC-030 §4–§5）。

所以卡片不能照厂商资料写"800 比 160 颗粒粗"，否则和用户看到的画面不符。两个方案：

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A（建议）** | 颗粒档显示**本软件实际渲染**的颗粒；彩色负片的颗粒档旁注明"当前版本彩色负片颗粒相近"，同时显示 ISO | 卡片与画面一致 | 彩色负片的颗粒档几乎都一样，对选择帮助有限 |
| B | 彩色负片暂不显示颗粒档，只显示 ISO；黑白胶片和反转片照常显示 | 不展示没有区分度的信息 | 不同类型的卡片项目不统一 |

RFC-030 给彩色胶片做了每款单独的颗粒量之后，两个方案都改为直接显示实测档位。

### 3.7 不靠悬停的入口与辅助功能

- 只有悬停一种入口不够：键盘用户、不方便悬停的用户都看不到。胶片分区和相纸分区标题的「•••」菜单各加一项「关于当前胶片 / 相纸」，打开当前选中款的卡片，按 Esc 关闭。
- 行的 `help`（系统提示文字）和辅助功能提示（VoiceOver 朗读的内容）填一句话简介，作为卡片的文字版兜底。

## 4. 功能 B：场景筛选

### 4.1 形态

胶片列表顶部加一排标签，排不下时自动换行：

```
▽ 胶片                                    ↺  •••
   [全部] [人像] [风景] [街拍日常] [弱光夜景]
   [室内灯光] [电影感] [复古怀旧] [黑白]
   正片
   Fujifilm Provia 100F
   Fujifilm Velvia 100
   负片
   Kodak Portra 400        ← 当前胶片
   …
```

### 4.2 词表（草稿，待决 Q2）

| 标签 | 含义 | 判定依据 |
|---|---|---|
| 人像 | 肤色好看、反差柔和 | 人工标注（草稿） |
| 风景 | 颗粒细、饱和度高或色彩准确 | 人工标注（草稿） |
| 街拍日常 | 宽容度大，随手拍不容易失败 | 人工标注（草稿） |
| 弱光夜景 | 高感光度或增感冲洗 | ISO ≥ 500 或增感冲洗的自动打上；其余可人工追加（如 HP5 Plus 400） |
| 室内灯光 | 按钨丝灯平衡 | 配置文件 `info.reference_illuminant` 为 `T`（自动：Vision3 200T、500T） |
| 电影感 | 电影负片 | 目录 `use` 为 `cine`（自动） |
| 复古怀旧 | 偏暖、民用胶片的味道 | 人工标注（草稿） |
| 黑白 | 黑白胶片 | 目录 `monochrome`（自动） |

能由数据推导的标签由生成脚本自动打，不需要人工维护；其余是人工标注，见附录 B。

### 4.3 规则

- 每次只选一个标签，默认"全部"。
- 保留现有分组（正片 / 负片 / 黑白）。不符合的胶片隐藏；整组都被隐藏时，组标题也不画。
- **当前胶片始终可见**：即使不属于所选场景也照常显示，文字变暗，悬停说明"当前胶片不属于此场景"。它仍可点击，不是禁用状态。
- 筛选**只影响显示**：不改变当前胶片，也不写任何设置。
- 筛选状态**不跨启动保存**，每次启动回到"全部"，避免用户以为胶片不见了。
- **相纸列表不筛选**：只有 9 款，而且选胶片时会自动配上默认相纸。

## 5. 功能 C：风格

### 5.1 位置与形态

左栏新增分区 **风格 / Styles**，放在"设置剪贴板"之后、"胶片"之前（左栏现有顺序见 `Panels/LeftPanel.swift` 第 23–40 行）。

```
▽ 风格
   内置
   自然人像                 Portra 400 · Portra Endura
   电影感·夜景              Vision3 500T · Vision 2383
   经典黑白                 Tri-X 400 · Multigrade IV RC
   …
   我的风格
   我的街拍                 胶片&相纸 · 胶片效果
   ( ＋ 存为风格 )
   已选 12 张：点一个风格即应用到这 12 张          ← 只在选中多张时出现
```

- 每个风格一行：名称加一句说明。内置风格写胶片和相纸，我的风格写包含哪些分组。
- 悬停内置风格，显示它的胶片卡片（复用 §3），外加风格说明。
- **风格是一个动作，不是一种状态**：应用后列表里不标记"当前风格"。照片后来又被改过的话，"当前是哪个风格"就没有确切答案了。

### 5.2 应用规则

- 点一个风格，作用于**所有选中的照片**，目标集合和"粘贴到 N 张"完全相同（`Session.pasteTargets`：⌘ 点选的集合，始终包含画布上那一张）。
- 画布上的照片立即改变，可以用一次 ⌘Z 撤销。
- 其他选中的照片立即写入 sidecar，旧的打印结果作废并标记为待渲染，打开时按新设置冲洗。这些照片不能撤销。状态栏报告写入了几张、失败了几张（与剪贴板 PRD 的 R2、R4 相同）。
- 批量导出期间不可用（`AGENTS.md` 陷阱 34）。

### 5.3 内置风格

- **只写这些字段**：
  - 胶片（`filmStock`）和相纸（`printStock`）；
  - 完整的效果块：颗粒、光晕、眩光三个开关（`grainActive`、`halationActive`、`glareActive`），以及 `EffectStrengths` 的全部字段：颗粒、分层颗粒、光晕、去防光晕层、高光增强、散射、成色剂开关与强度、眩光（`Model/Params.swift` 第 383 行起）。
  - 效果块里风格没写到的字段一律取默认值。所以先后套用两个风格，结果只取决于后一个。
- **不写**：画幅（135 / 120、方向、长度）、曝光、白平衡、场景置位、蒙版、裁切与几何、冲洗后调整、片边、数据背。画幅属于照片本身的物理尺寸，如果内置风格改了它，同一个风格在 135 和 120 照片上的颗粒粗细会不同。
- **遵守胶片列表的规则**，结果与在列表里点选同一款胶片一致（`Session.selectFilmStock`、`Session.applyFilmStageRule`）：
  - 负片：用风格指定的相纸；没指定时用这款胶片的默认相纸；同时清掉"数字中间片"和"直接扫描"的选择。
  - 黑白胶片只能配黑白相纸（`StockCatalog.canPrint`）。
  - 反转片：直接扫描，不经相纸；相纸选择保持原样，下次换回负片时恢复。
- 内置风格清单见附录 D（草稿，待决 Q6）。
- 内置风格不能修改、不能删除。

### 5.4 我的风格

- 点「＋ 存为风格」，打开一个小面板：
  - 名称：必填，不能与已有风格重名；
  - 7 个分组的勾选框，含义与设置剪贴板完全相同（胶片&相纸、曝光、白平衡、胶片效果、相纸效果、场景置位、遮罩，即 `ClipboardGroup`），默认沿用剪贴板当前的勾选。遮罩分组在相关功能关闭时不显示（`ClipboardGroup.offered`）。
- 保存的是**画布上那张照片**在所勾选分组里的设置。
- **存设置，不存解算结果**，与剪贴板 PRD §3 一致：
  - 曝光：存测光方式和补偿量，目标照片自己测光；
  - 白平衡："As Shot"在目标照片上取它自己的相机值；
  - 场景置位：存回拉量，在目标照片上重新拟合曲线；
  - 放大机滤色：存相对于目标照片解算结果的偏移量。
- 与内置风格的差别：勾了"胶片效果"就**包含画幅**，因为剪贴板的这个分组本来就包含画幅（用户 2026-09-28 的决定）。面板上要写明这一点。
- 片边、数据背不进入任何风格。剪贴板对它们是否单独成组仍未决（`notCopied` 里的 F10），风格跟随剪贴板。

### 5.5 存储

- 文件：`~/Library/Application Support/SpektraLab/styles.json`。规则参照导出配方的 `export-recipes.json`（`Export/ExportRecipe.swift` 的 `ExportRecipeStore`）：
  - 原子写入，启动时读一次；
  - **读坏不致命**：文件被手工改坏时，回退为只有内置风格，并在风格分区提示问题；
  - 文件路径可注入，测试不碰用户的真实文件。
- 文件带格式版本号。
- **只保存所勾选分组的字段**，不保存来源照片的其他内容（例如裁切），也不保存来源照片的路径。

### 5.6 管理与失效

- 我的风格：右键可改名、删除；删除要确认。
- 排序：内置风格按附录 D 的顺序；我的风格按创建时间，新的排在后面。

## 7. 行为规则

- **R1 卡片只读。** 显示卡片不改变参数、不写 sidecar、不触发渲染。
- **R2 卡片不挡操作。** 不抢键盘焦点；卡片显示时，点击和滚动照常工作。
- **R3 筛选只影响显示。** 不改变当前胶片；当前胶片始终可见。
- **R4 风格的作用对象与粘贴相同。** 作用于 `pasteTargets`；选中多张时，分区底部写明张数。
- **R5 风格遵守胶片列表的规则。** 结果与在列表里点选同一款胶片相同，包括自动配相纸、黑白配黑白相纸、反转片直接扫描。
- **R6 内置风格只写 §5.3 列出的字段。** 其他字段逐个保持不变。
- **R7 我的风格存设置，不存解算结果。** 目标照片自己测光、自己取 As Shot 白平衡、自己拟合场景置位。
- **R8 撤销。** 画布上的照片一步撤销；其他照片不能撤销，状态栏报告写入和失败的张数。
- **R9 离线照片立即生效。** 不在画布上的选中照片立即写 sidecar，旧打印作废并标记待渲染；打开时按新设置冲洗，不会先显示旧效果。
- **R10 批量导出期间风格不可用。** 筛选和卡片照常可用。
- **R11 不改材质。** 风格不修改任何胶片或相纸的配置文件。
- **R12 失效要说明。** 引用了不存在的胶片或相纸的风格灰显并说明原因。
- **R13 半格拼接。** 风格作用于半格拼接时，按粘贴的同一套规则处理；具体行为在 RFC 中核实。

## 附录 A：指标测量方法

- **脚本**：建议放在 `engine/tests/stock_traits.py`，通过 `engine/tests/spk_ctypes.py` 调用引擎动态库，结果写到 `modern_UI/stock_traits.json`。只需要 `engine/build.sh dylib`，不需要上游 Python 参考实现（与 `engine/tests/bw_checks.py` 相同）。构建动态库需要 Xcode 26.6 和 Metal 工具链。
- **共同设置**：
  - 胶片配它的默认相纸；反转片直接扫描。彩色相纸用 Kodak Portra 400 作参考胶片来测，黑白相纸用 Kodak Tri-X 400；
  - 其他参数取默认值；
  - 关掉颗粒和眩光，保证结果逐位可复现（`AGENTS.md` 陷阱 1）；
  - 关掉自动曝光：输入已经按测光轴排好。
- **反差**：合成一条中性灰阶（场景 EV −6 到 +6），渲染后得到输出亮度随场景 EV 变化的曲线。在中灰 ±1 EV 范围内做线性拟合，斜率就是"中间调反差"。
- **饱和度**：一组固定色块（建议用公开的 24 色标准色卡数值，具体来源实现时确认），在 0 EV 下渲染，计算输出的平均 CIELAB 色度 C\*ab，报告为与输入平均色度的比值。
- **宽容度**：用 `spk_scene_latitude` 测出介质边界，即中灰以上和以下各能容纳多少档，报告总档数。这是**影调**宽容度。
- **颗粒**：
  - 黑白胶片：颗粒强度已按厂商公布的 RMS 颗粒度（均方根颗粒度）校准（提交 `0bca29d`），直接测渲染结果；
  - 彩色胶片：用 `research/colour-film-granularity.md` §3 的方法测渲染结果；显示方式见 §3.6；
  - 厂商资料里的颗粒数值单位不统一，有 RMS、PGI（Print Grain Index，印刷颗粒指数）和颗粒度曲线三种，不能放在同一把尺子上比较。只在悬停说明里列出原值和资料编号。
- **输出内容**：每款的原始数值、测量日期、引擎构建标识（`spk_build_info`）。档位由 `gen-catalog.py` 计算。
- **重跑时机**：胶片或相纸的配置、渲染节点有改动之后。守卫测试检查数据覆盖了目录中的每一款。

## 附录 C：示意图设计规范（给设计师）

- **数量**：33 张，每款一张，文件名为 `<stock_id>.svg`（id 见附录 B），放在 `modern_UI/stock_art/`。
- **格式**：SVG 矢量图，不嵌入位图，文字转为路径。应用里用资源目录（Asset Catalog）的矢量资源还是 PDF，由实现阶段决定（macOS 直接读取 SVG 文件的系统版本要求未核实）。
- **模板**：按类型分 6 种外形。同一类型的外形完全一致，只换颜色和文字：

| 模板 | 用于 |
|---|---|
| 135 暗盒 | 彩色负片、反转片 |
| 135 暗盒（黑白配色） | 黑白负片 |
| 电影胶片片盘 | 电影负片 |
| 彩色相纸盒 | 彩色相纸 |
| 黑白相纸盒 | 黑白相纸 |
| 拷贝片片盘 | 电影拷贝片 |

- **颜色**：按类型配色，同一类型用同一主色，帮用户记住"这一类是什么"。是否用品牌配色待负责人决定（Q4）。
- **文字**：图上用大号数字写感光度（相纸写类型），是否写胶片名待定（Q4）。**不画厂商标志，不仿制包装图案和版式。**
- **尺寸与可读性**：按卡片里约 96 × 96 pt 设计，缩到 48 pt 时感光度数字仍可辨认；在深色背景（左栏和卡片的底色，见 `Theme/Theme.swift`）上清晰。
- **交付**：矢量源文件、33 张导出的 SVG，再加一张 33 款并排的总览图，供审阅。
